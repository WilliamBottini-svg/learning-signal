# ChatGPT Custom GPT — Conversation Starters

These are the **conversation starters** shown as clickable prompts on the Custom GPT's landing screen.
They are **real content** (not a stub): paste each line, verbatim, into a "Conversation starters" slot
in the GPT builder. ChatGPT shows 4 on the landing screen and allows more; enter all six.

The set is chosen to exercise the coach's range — a jargon-free cold open (the most common real first
message), a restraint/diagnosis case, a redesign-without-banning case, two drafting offers, and the UME
domain adaptation — so a first-time user lands on the behavior the tool is built for.

1. My students are using ChatGPT on my homework — where do I start?
2. Check whether this assignment still shows student learning.
3. Help me redesign this assessment without just banning AI.
4. Draft student-facing AI-use language.
5. Review this rubric for learning signal strength.
6. Adapt this for undergraduate medical education.

## Notes for the builder
- **Order matters.** Starter 1 is the jargon-free cold open — an anxious educator with no assessment in
  hand; it triggers the reception layer's cold-open onboarding (orient + reframe from "stop cheating" to
  "protect the learning signal" + ask for one assignment in plain words). Starter 2 leads with the core
  diagnostic question (and invites a *restraint* answer when the assignment is already strong); starter 3
  frames redesign as proportionate, not prohibition.
- **Pin starter 1 first** so the 4 shown on the landing screen lead with the plain-language opener.
- **Keep them short** — the builder truncates long starters in the UI.
- These mirror the Gemini Gem starter prompts
  ([`../gemini-gem/starter-prompts.md`](../gemini-gem/starter-prompts.md)); keep the two lists aligned if
  either changes (the cold-open opener should exist in both).
