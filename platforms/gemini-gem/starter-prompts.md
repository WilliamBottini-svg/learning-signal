# Gemini Gem — Suggested First Messages

> **Gemini Gems have no "conversation starters" feature.** Unlike a ChatGPT Custom GPT, a Gem can't ship
> clickable starter buttons. So these are **suggested first messages** — paste one into the chat to begin,
> share them alongside the Gem (in its share blurb, a course page, or a one-line "try asking…" note), or
> drop them into the Gem's first reply. Keep them short so they're easy to paste.
>
> Keep this list aligned with the ChatGPT Custom GPT conversation starters
> ([`../chatgpt-custom-gpt/conversation-starters.md`](../chatgpt-custom-gpt/conversation-starters.md)) if
> either changes.

## Suggested first messages

0. My students are all using ChatGPT on my homework and I don't know what to do — can you help? *(jargon-free cold open)*
1. Does this assignment still show what my students can actually do? Here's the task…
2. Help me redesign this assessment without just banning AI.
3. Draft student-facing language for how AI may be used on this assignment.
4. Review this rubric — is the learning signal strong, or is it rewarding polish?
5. Adapt your check for undergraduate medical education.

## Notes for the builder

- **Prompt 0 is the most common real opener** — anxious, no jargon, no assessment named yet. It exercises
  the Gem's **cold-open onboarding** path: orient, reframe "stop cheating" as "protect the learning signal,"
  and ask one plain question. Lead with it.
- The rest span the coach's range: the core diagnostic question (1, which can correctly return a *restraint*
  "it's fine" answer), proportionate redesign (2), two concrete drafting offers (3, 4), and the UME domain
  adaptation (5).
- Prompt 4 deliberately surfaces the construct-irrelevant-variance check ("rewarding polish") — a common
  real failure where a rubric pays out for AI-suppliable fluency rather than the learning.
- Because there are no clickable buttons, phrasing matters: each reads as a natural sentence a user would
  actually type or paste, not a button label.
