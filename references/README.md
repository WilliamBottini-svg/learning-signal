# References — rigor underneath

This is the **"rigor underneath"** layer referenced in [`../CLAUDE.md`](../CLAUDE.md) and the core files.
Plain language lives on top (in `core/`); the technical vocabulary, the framework provenance, and the
**dated, sourced** empirical claims live here, one layer deeper, for expert users and reviewers.

Nothing here changes the diagnostic logic. These files exist so that:

- the engine's framework attributions are **accurate and checkable** (Kane vs Messick vs Miller vs van
  der Vleuten — see [`validity-frameworks.md`](validity-frameworks.md)); and
- empirical claims that age (notably "AI detectors are unreliable") are stated **with a date and a
  source**, and clearly separated from the **accuracy-independent principle** the safety gate actually
  rests on (see [`ai-detection-and-academic-integrity.md`](ai-detection-and-academic-integrity.md)).

Citations are given to the level the authors are confident about; where a precise page or edition is
uncertain it is described rather than invented. Treat this as a working bibliography, not a systematic
review.
