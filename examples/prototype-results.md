# Prototype Results (fill-in template)

> **Status: template.** This file is where real prototype runs of Learning Signal Check get recorded —
> the coach's *actual* outputs when tested on real (but de-identified) assessments. Polished,
> illustrative demonstrations live in the other `examples/` files; this file holds raw run logs.
>
> **De-identification (required):** no PHI, no real student records or grades, no real student or
> institution names. Fictionalize or redact before pasting. See [`../AGENTS.md`](../AGENTS.md).

## How to use
Copy the block below for each prototype run. Keep entries dated. To score a run, use the five-dimension
rubric + binary gates in [`../tests/scoring-rubric.md`](../tests/scoring-rubric.md) and record it with
[`../tests/test-results-template.md`](../tests/test-results-template.md).
